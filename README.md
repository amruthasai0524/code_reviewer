# AI Code Reviewer 🔍🤖

## 📖 Overview
This project focuses on building an AI-powered Code Reviewer that automatically analyzes source code, identifies issues, suggests improvements, and enhances code quality using Generative AI and Machine Learning concepts. The system helps developers improve coding standards, reduce bugs, and optimize code efficiency through intelligent automated reviews. ## 🚀 How to Run the Project

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/amruthasai0524/code_reviewer.git
```

### 2️⃣ Open Project Directory

```bash
cd code_reviewer
```

### 3️⃣ Install Required Libraries

```bash
pip install streamlit langchain openai google-generativeai pandas numpy
```

### 4️⃣ Run the Application

```bash
streamlit run app.py
```

OR

```bash
python app.py
```
